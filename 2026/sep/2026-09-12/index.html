Insert rate compares tonight’s gathered records against mentions the sentiment stage cleared in the same window, so it is a pipeline-lag measure, not a loss measure — and for the fourth night it is close to meaningless as a percentage. Read the two columns as different units: gathered counts billed API records including duplicates filtered before storage, while inserted counts mentions the sentiment stage wrote out, whenever they were collected.
