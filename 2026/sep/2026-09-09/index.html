Insert rate compares tonight’s gathered records against mentions the sentiment stage cleared in the same window, so it is a pipeline-lag measure rather than a loss measure, and it oscillates with the backlog. At 353% it is far outside the 39–83% band of the previous eight nights, and every platform reads above 250%. The excess is 19,923 mentions; the shortfall accumulated over Sep 1–8 was 11,474, so the drained queue predates this month. Read the two columns as different units rather than a conversion: gathered counts billed API records including duplicates that are filtered before storage, while inserted counts mentions the sentiment stage wrote out, whenever they were collected. The practical consequence is that tomorrow’s inserted column should fall back toward the size of tomorrow’s haul now that the queue is short; if it stays this high, the backlog is deeper than one night could clear. Keywords w/ new mentions = the platform’s sentiment-job count minus its {"analyzed":0} bucket; 400 of the 816 keyword-platform pairs produced something, against 252 of 791 last night. API calls are the fixed per-keyword request counts, which is why cost tracks keyword count as much as it tracks volume.
